## 3 — Full grading and instructor feedback (in progress)

Implemented increments: deterministic multiple-select with explicit all-or-nothing and clamped equal-share correct-minus-incorrect policies; learner-facing scoring rules; response-shape/duplicate/index checks; an original biology practice item; SHA-256 question-specification digests for new attempts; and an explicit package-version update path preserving previous attempt records. Alembic migration 0002 adds a nullable digest; historical attempts remain unpinned and retain practice-v1. Numeric grader v3 converts a constrained, documented subset of SI and biological units with exact rational scales, dimensional checks, bounded product/quotient/power parsing and absolute tolerance in the authored unit. Grader v4 adds bounded relative tolerance using `absolute + relative × |answer|`. Grader v5 checks optional lexical significant-figure requirements (1–12) only after unit conversion and tolerance. Objective evidence v1 reports best points per distinct tagged item, separates retry counts from breadth, and exposes a provisional study indicator only after at least three distinct items, 80% objective-item coverage and 80% best-point performance. The thresholds and policy version are visible to learners; the UI explicitly says this does not certify mastery. Tests cover conversion, incompatibility, unsupported units, matched dimensions, tolerance boundaries, precision notation, invalid policies, objective breadth/retries, and adversarial inputs.

Implemented increments: finite authored formative variants selected reproducibly from signed seven-day tokens, bound to course/version/question; resolved prompts/options/specs stay server-side except for the whitelisted learner DTO; variant IDs and exact per-variant digests are saved per attempt. Each variant is validated as a standalone resolved question. The biology seed includes three distinct forms for one formative check. A bounded SymPy plugin checks rational-expression equivalence using an AST allowlist, explicit assumptions and complexity caps; one original calculus quotient-rule practice item exercises it. This does not generate randomized numeric parameters, support general symbolic math, or add protected exam variants.

Revision 0006 closes the submission-store, safe question delivery, schedule/attempt enforcement and gradebook-calculation connection for existing deterministic question types. The strict-deadline policy is the only accepted late-work rule. This vertical slice is tested with a synthetic graded fixture because no current package has adequate summative content. Remaining: human appeals and manual overrides for graded results; immutable package archives and historical regrading; general graph/table/data responses and arbitrary CSV analysis; design rubrics; numeric parameter generation with independent recalculation; robust objective mastery from diverse assessment; retention and transfer; evidence-linked misconception feedback; credential-safe optional providers; and an actually isolated code worker. The CSV implementation is limited to small UTF-8 tables with exact headers and authored numeric output checks. The symbolic plugin supports rational functions only; general symbolic calculus remains unsupported. Unknown and affine units fail closed; a few contextual legacy labels are exact-label-only. Add adversarial/mutation tests for every plugin. Code stays disabled until isolation is demonstrated; never mount a Docker socket in the API or worker.

The `practice-v7` increment adds a narrow data-interpretation composite: a separate unit-checked numeric calculation and evidence-bounded multiple-choice conclusion receive independent points. Incomplete fields earn only the points they satisfy; unknown fields, malformed values and prompt-injection text do not gain credit. A new original statistics reading and practice item exercise the path. This does not grade prose, graphs, general tables, causal explanations, or keyword overlap; reasoning remains unassessed.

The `practice-v8` increment adds structured analytic rubrics mapped to explicit categorical response fields. Every rubric criterion, response field, answer specification, and point weight must align. The biology example asks learners to discriminate a matched control, direct promoter occupancy, motif dependence, and the scope of a causal claim. Each receives independent points through the standard deterministic choice grader. It is not free-text short-answer grading; learner prose and keyword overlap remain ungraded. The course stays partial and advances from 0.3.0 to 0.3.1 without acquiring semester equivalence.

The `practice-v9` increment adds a constrained CSV numeric-table upload. A cell-biology activity asks learners to summarize two small replicate groups and awards independent credit for row counts and arithmetic means. The upload is size-limited, parsed as UTF-8 text, checked against an exact header and known row keys, and never executed. Its manifest includes source values and `count`/`mean` operations that the content validator independently recalculates. It does not support general CSV analysis or score a causal explanation; the course remains partial.

The `practice-v10` increment adds a bounded interactive scatter plot. Learners calculate means from visible source replicates, enter coordinates for a fixed set of axes, and receive separate deterministic credit for each coordinate. An accessible live SVG and data table provide a visual check; expected coordinates stay server-side, while the content validator independently recalculates the means. It does not assess graph selection, custom axes, uncertainty displays, interpolation, or scientific interpretation. The statistics package remains partial.

Appeals/overrides increment: learners may request one human review per immutable attempt. Alembic revision 0003 stores one appeal and append-only decision; revision 0004 adds an operator-provisioned instructor role. No registration field, email allowlist or HTTP path can grant reviewer access. The CLI grants/revokes roles for existing registered accounts. Decisions distinguish adjusted formative score, upheld score and declined request; the automatic result remains intact. The instructor queue resolves the saved variant, shows its safe question DTO and checks the question-specification digest. Adjusting/upholding is blocked for missing, unpinned, stale or changed specifications. Backend regressions exercise claimed instructor fields, forged email environment settings, alternate prompts/options, same-version content edits, stale packages, own-attempt denial, score bounds and audited persistence. A frontend component test verifies prompt/option/response rendering and disables non-decline decisions when content no longer matches; the browser flow verifies that self-registration cannot access the instructor queue. Historical packages are not archived, so unsupported old content can only be declined. This remains a narrow formative exception path, not protected exams, full course grading or institutional review.
