# Estimation, confidence intervals, and effect sizes

A 95% confidence procedure has 95% long-run coverage when its assumptions hold; after observing a particular interval, it is not correct to say there is a 95% probability the fixed parameter lies inside it in the frequentist model. A narrow interval can reflect precision but not freedom from bias. Report effect sizes and intervals alongside tests, and define the estimand before selecting analysis. Units and the reference comparison make results interpretable.
