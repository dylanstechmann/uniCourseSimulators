# Experimental design, regression, and reproducibility

Randomization supports unbiased comparisons; blocking controls known nuisance variability; blinding reduces measurement and analysis bias. Replication should match the unit of inference: cells nested within wells or wells nested within animals are not automatically independent. Regression describes conditional relationships under a model and can adjust measured covariates, but unmeasured confounding remains possible. Residual plots, influence checks, preregistered outcomes, and transparent code help assess reliability.
