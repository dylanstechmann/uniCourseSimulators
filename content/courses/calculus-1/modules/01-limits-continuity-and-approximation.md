# Limits, continuity, and approximation

A limit describes the value approached as an input approaches a point; it need not equal the function's value there. Continuity at a requires the function to be defined at a, the limit to exist, and the two values to agree. The derivative later formalizes the best local linear approximation. When applying a model near a reference state, quantify the neglected higher-order terms and do not extrapolate a local approximation far outside that state.
