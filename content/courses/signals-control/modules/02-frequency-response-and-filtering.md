# Frequency response and filtering

For a stable LTI system, sinusoidal inputs produce sinusoidal steady-state outputs at the same frequency with changed gain and phase. Frequency response G(jω) supports filter and sensor design. Bandwidth describes the range over which a system meets a specified response criterion; it is not a single universal property without a criterion. Sampling must capture relevant dynamics, while anti-alias filters limit unresolved frequencies and sensor bandwidth constrains what can be measured.
