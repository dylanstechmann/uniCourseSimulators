# Thermochemistry and state functions

The first law is ΔU = q + w when work done on the system is positive. Enthalpy H = U + PV is useful for constant-pressure processes; ΔH is approximately the heat transferred at constant pressure when only PV work occurs. Standard reaction enthalpy follows ΔH°rxn = ΣνΔH°f(products) − ΣνΔH°f(reactants). A state function depends on initial and final states, not path, so Hess's law allows reaction steps to be added algebraically.
