# Planning, sensing, and closed-loop execution

A path plan specifies feasible motion through a modeled environment; feedback corrects deviations using sensor observations. Localization uncertainty, actuator limits, latency, and obstacle uncertainty affect execution. A robust system monitors safety constraints online and enters a defined safe state on sensor loss or collision. For lab automation, repeatability, contamination boundaries, calibration, and recovery after interrupted protocols are as important as nominal trajectory accuracy.
